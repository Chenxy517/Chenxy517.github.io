# Xingyu Chen — Academic Homepage

A lightweight static academic website for GitHub Pages. No server is required.

## Deployment
1. Create a public GitHub repository named `Chenxy517.github.io`.
2. Upload all files in this ZIP **to the repository root** (not a subfolder).
3. In Settings → Pages, choose Deploy from a branch, `main`, `/ (root)`.
4. Visit `https://chenxy517.github.io` after deployment completes.

## Site contents
- `index.html`: About, research interests, publications, projects, CV
- `style.css`: responsive design
- `script.js`: mobile navigation and footer year
- `portrait.jpg`: portrait from your uploaded photograph
- `cv.pdf`: your uploaded CV

Publication status reflects the supplied CV; update as submissions change.
